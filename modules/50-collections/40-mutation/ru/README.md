Через изменяемый срез можно обновить элементы массива или вектора без передачи владения. В этом уроке вы запишете новые значения через `&mut T` и отсортируете последовательность. Длина исходной коллекции останется прежней.

Параметр `&mut [i32]` даёт доступ к существующим элементам. Цикл получает изменяемую ссылку на каждый элемент, а оператор `*` позволяет записать новое число.

```rust
pub fn double(values: &mut [i32]) {
    for value in values {
        *value *= 2;
    }
}
```

Во всех примерах с удвоением числа по модулю не превышают `1000000`. Вызов с `[3, 1]` превратит массив в `[6, 2]`. Ссылку `&mut Vec<i32>` тоже можно передать в такой параметр. Функция меняет данные владельца и возвращает `()`.

## Сортировка

Метод `sort` упорядочивает срез на месте. Для целых чисел по умолчанию используется порядок по возрастанию.

```rust
pub fn double_and_count(values: &mut [i32]) -> usize {
    for value in &mut *values {
        *value *= 2;
    }
    values.len()
}

pub fn sort_values(values: &mut [i32]) {
    values.sort();
}
```

Функция `double_and_count` для `[3, -1, 2]` изменит числа на `[6, -2, 4]` и вернёт длину `3`. Отдельная `sort_values` упорядочит переданные числа по возрастанию. Выражение `&mut *values` повторно заимствует данные на время цикла. Благодаря этому исходная ссылка `values` остаётся доступной для чтения длины после обхода. Если передать саму изменяемую ссылку в цикл по значению и затем попытаться использовать её снова, компилятор может сообщить о перемещении ссылки.

Метод `sort` сохраняет относительный порядок равных элементов. У `sort_unstable` такой гарантии нет. Различие станет заметно на записях с одинаковыми ключами сортировки. Для одних целых чисел оба метода дают одинаковую упорядоченную последовательность значений.

Обычная сортировка требует полного порядка `Ord`. Целые числа его поддерживают. У `f64` этого поведения нет из-за значений вроде `NaN`, для которых обычное сравнение не задаёт полный порядок. Подробно ограничения типов разберём в уроке об ограничениях трейтов.

Во время обхода самого вектора через `&mut values` нельзя одновременно вызвать `values.push(...)`. Увеличение буфера могло бы сделать ссылку на элемент недействительной. У среза метода `push` вообще нет, потому что срез не управляет длиной вектора.
