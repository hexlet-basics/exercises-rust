Способ обхода коллекции в Rust определяет владение элементами после цикла. В этом уроке вы сравните передачу вектора по значению с обходом по общей ссылке. Затем вычислите результат, сохранив исходные строки у владельца.

Запись `for name in names` для переменной типа `Vec<String>` потребляет вектор. В каждой итерации переменная `name` получает владение очередной строкой.

```rust
pub fn join_names(names: Vec<String>) -> String {
    let mut result = String::new();
    for name in names {
        result.push_str(&name);
    }
    result
}
```

После цикла переменную `names` использовать нельзя. Каждая строка `name` освобождается после своего прохода, а функция возвращает новую строку результата. Если исходные строки ещё нужны, выберите заимствование.

```rust
pub fn show_names(names: &[String]) {
    for name in names {
        println!("{}", name);
    }
    println!("Items: {}", names.len());
}
```

Параметр уже содержит общую ссылку на последовательность. Цикл получает элементы типа `&String`, не перемещая их. После цикла срез и его данные остаются доступны. На месте вызова можно передать `&vector` или `&array`.

Если переменная имеет тип `Vec<T>`, запись `for value in &values` создаёт общий доступ на время обхода. Для параметра `&[T]` дополнительный знак `&` не нужен. Чтобы выбрать форму обхода, определите тип выражения справа от `in`.

Для числовых элементов цикла можно читать значение через `*value`, потому что `i32` копируется. Для вызова метода у `&String` Rust автоматически разыменует ссылку. Метод `.len()` по-прежнему считает байты, даже когда строка находится внутри коллекции.

Изменяемый обход использует `&mut` и даёт ссылки с правом записи. Этот вариант разберём в следующем уроке вместе с ограничениями изменения длины вектора.
