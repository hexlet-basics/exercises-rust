Если количество элементов меняется при выполнении, используйте `Vec<T>`. В этом уроке вы создадите вектор и добавите в него значения. Затем вернёте владение коллекцией вызывающему коду.

Запись `Vec<i32>` означает вектор целых чисел. Угловые скобки задают тип элементов. Макрос `vec!` создаёт вектор из перечисленных значений.

```rust
pub fn starting_prices() -> Vec<i32> {
    let mut prices = vec![100, 200];
    prices.push(300);
    prices
}
```

Метод `push` добавляет один элемент в конец и требует изменяемого доступа. После вызова вектор содержит `[100, 200, 300]`. Для пустого вектора есть `Vec::new()`; тип можно задать аннотацией или позволить компилятору вывести его из последующих добавлений.

Вектор владеет буфером элементов и освобождает его при завершении владения. Присваивание вектора другой переменной перемещает владение, как у `String`. Сам тип `Vec<i32>` не поддерживает `Copy`, хотя отдельный элемент `i32` копируется.

К вектору применяются `.len()` и индексация с проверкой границ.

Запись `Vec<T>` описывает семейство типов. Когда вместо `T` указано `i32`, получается вектор целых чисел, а `Vec<String>` хранит строки. Так же читаются уже знакомые `Option<T>` и `Result<T, E>`. Писать собственные обобщённые функции для этого не требуется.

Метод `pop` удаляет последний элемент и возвращает его в `Some`. Для пустого вектора он возвращает `None`. Например, у `let mut values = vec![10, 20];` вызов `values.pop()` даст `Some(20)`, а вектор сохранит только `10`.

Для чтения без удаления подходит `get`. Вызов `values.get(0)` возвращает `Option<&i32>`, поэтому отсутствие индекса можно обработать без паники.
