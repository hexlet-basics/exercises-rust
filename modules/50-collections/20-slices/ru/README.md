Чтобы принимать набор чисел любой длины без копирования, функция может использовать срез. В этом уроке вы примете последовательность через параметр `&[i32]` и обработаете массив, вектор или их часть одной функцией.

Ссылка на срез `&[i32]` хранит адрес первого элемента и длину. В отличие от `[i32; 3]`, тип `&[i32]` не задаёт число элементов на этапе компиляции.

```rust
pub fn count_negative(values: &[i32]) -> usize {
    let mut count = 0;
    for value in values {
        if *value < 0 {
            count += 1;
        }
    }
    count
}
```

Вызов `count_negative(&[10, -20, -30])` вернёт `2`. Если есть массив `prices`, выражение `&prices[1..3]` создаст срез двух элементов с индексами `1` и `2`. Вызов `count_negative(&prices)` передаст весь массив.

Срез может быть пустым. Тогда его длина равна нулю, цикл не выполняет ни одного прохода, и `count_negative` возвращает `0`.

Запись `&values[1..]` берёт все элементы после первого. Для пустого среза граница `1` выходит за его пределы и вызывает панику. Это ограничение нужно учитывать при выборе части последовательности неизвестной длины.

Для вектора `let prices = vec![10, -20, 30];` вызов `count_negative(&prices)` тоже допустим. Rust преобразует `&Vec<i32>` в `&[i32]` без копирования элементов. Аналогично `&mut Vec<i32>` можно передать в параметр `&mut [i32]`. Срез разрешает доступ к существующим элементам, но не изменение длины вектора.

Общая ссылка `&[i32]` разрешает читать элементы. Для их изменения понадобится `&mut [i32]`. Границы среза проверяются при выполнении, поэтому неправильный диапазон может вызвать панику. Срез при этом не владеет элементами и не должен пережить исходную последовательность.

При обходе `for value in values` параметра типа `&[i32]` цикл получает общие ссылки `&i32`. Оператор `*value` читает число по ссылке. Он не перемещает данные, потому что `i32` копируется. Далее подробнее разберём, как способ обхода влияет на владение элементами.
