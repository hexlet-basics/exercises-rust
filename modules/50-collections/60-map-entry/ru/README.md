Для накопления значений по ключу в Rust подходит API `entry`. В этом уроке вы получите существующую запись или создадите начальную, затем измените её через ссылку. Это избавляет от отдельного поиска перед каждым добавлением.

Вызов `map.entry(key)` представляет доступ к записи с указанным ключом. Метод `or_insert(default)` оставляет существующее значение или вставляет указанное начальное. В обоих случаях он возвращает изменяемую ссылку на значение.

```rust
use std::collections::HashMap;

pub fn group_by_day(entries: Vec<(String, i32)>) -> HashMap<String, Vec<i32>> {
    let mut result = HashMap::new();
    for (day, value) in entries {
        let group = result.entry(day).or_insert(Vec::new());
        group.push(value);
    }
    result
}
```

Вход содержит пары из дня и числа. Деструктуризация в `for` сразу даёт два имени. Цикл получает владение парами и передаёт строковый ключ в таблицу. Значением таблицы здесь является вектор, поэтому для каждого дня можно собрать несколько записей.

Если день встретился впервые, `or_insert(Vec::new())` создаёт для него пустой вектор. В последующих проходах готовая группа сохраняется. Переменная `group` имеет тип `&mut Vec<i32>`, и `push` добавляет очередное число. Для пар `("Mon", 10)`, `("Tue", 5)`, `("Mon", 7)` получатся группы `Mon = [10, 7]` и `Tue = [5]`.

Начальным значением может служить и число. Например, `entry(key).or_insert(0)` возвращает изменяемую ссылку на существующее либо нулевое значение. Такой доступ позволяет обновлять счётчик через знакомый оператор `*`.

Чтобы прочитать таблицу без перемещения, можно пройти по общей ссылке. В функции с параметром `&HashMap<String, i32>` цикл `for (key, value) in map` получает ссылки на ключ и значение. Порядок пар не гарантируется.

Изменяемая ссылка на запись подчиняется обычным правилам заимствования. Пока она нужна, нельзя выполнять другое конфликтующее изменение таблицы. В показанном цикле доступ к `group` заканчивается до следующего вызова `entry`.

Точный внутренний тип результата `entry` сейчас разбирать не требуется. Для применения достаточно понимать выбор существующего или начального значения и возвращаемую ссылку.
