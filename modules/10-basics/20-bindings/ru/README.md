В Rust переменная по умолчанию запрещает повторное присваивание. В этом уроке вы выберете между `let`, `let mut` и затенением. Это поможет явно указать, какие значения программа меняет во время работы.

Синтаксис `let price = 200;` связывает имя со значением. Тип часто выводится автоматически. Если затем написать `price = 180;`, компилятор сообщит, что неизменяемой переменной нельзя присвоить новое значение.

Для счётчика или меняющегося остатка добавьте `mut`.

```rust
pub fn show_stock() {
    let mut stock = 10;
    stock -= 2;
    stock += 5;
    println!("{}", stock);
}
```

Программа напечатает `13`. Оператор `-=` уменьшает значение на указанное число, `+=` увеличивает. Обычное присваивание тоже доступно, например `stock = stock + 1;`.

Повторный `let` создаёт новую переменную с тем же именем. Этот приём называют затенением. Предыдущее значение доступно при вычислении правой части.

```rust
pub fn show_price() {
    let price = 500;
    let price = price - 50;
    println!("{}", price);
}
```

Здесь новая `price` равна `450`. Затенение не требует `mut` и допускает изменение типа новой переменной. Используйте его для последовательных преобразований, если прежнее значение больше не нужно. Для имён из нескольких слов в Rust принято написание `snake_case`.

## Константы

Объявление `const STEP: i32 = 5;` задаёт константу с явным типом. У константы тип обязателен. Запись `const STEP = 5;` без типа не скомпилируется. Значение константы должно вычисляться на этапе компиляции. Имена констант обычно пишут заглавными буквами с подчёркиваниями. Добавить `mut` к константе нельзя. Неизменяемый `let` при этом может получить значение, рассчитанное во время выполнения.

Чтобы вывести исходное и преобразованное значения, передайте их в `println!` после строки. Например, `println!("Start: {}. End: {}", start, end);` подставит два значения по порядку. Число `i32` хранит целые со знаком; числовые типы подробно рассмотрим дальше.
