Rust предоставляет `for` для последовательностей, `while` для повторения по условию и `loop` для цикла с выходом из тела. В этом уроке вы сравните их запись и разберёте диапазоны. Особенность Rust заключается в том, что `loop` может вернуть значение через `break`.

## Диапазоны и for

Диапазон `1..4` содержит `1`, `2` и `3`. Правая граница не включается. Запись `1..=4` включает и `4`. В `for` переменная очередного элемента объявляется самим циклом.

```rust
pub fn factorial(limit: i32) -> i32 {
    let mut product = 1;
    for number in 1..=limit {
        product *= number;
    }
    product
}
```

В примере `limit` находится между `0` и `10`, чтобы произведение помещалось в `i32`. При `limit = 4` функция вернёт `24`. Диапазон `1..=0` пуст, поэтому для нуля результатом останется `1`. Обход по убыванию сам по себе не начинается.

## while и изменяемое состояние

Условие `while` должно иметь тип `bool`. Если состояние меняется в цикле, соответствующая переменная требует `mut`.

```rust
pub fn doubling_steps(start: i32, target: i32) -> i32 {
    let mut value = start;
    let mut steps = 0;
    while value < target {
        value *= 2;
        steps += 1;
    }
    steps
}
```

Оба аргумента примера положительные и не больше `1000000`. Вызов `doubling_steps(3, 20)` вернёт `3`. Параметры по умолчанию неизменяемы, поэтому здесь исходное значение копируется в локальную изменяемую переменную. Если начального значения достаточно, цикл не выполнится.

## loop и break со значением

Цикл `loop` не проверяет условие перед проходом. Команда `break` завершает его и может передать результат всему выражению.

```rust
pub fn halving_steps(start: i32) -> i32 {
    let mut value = start;
    let mut steps = 0;
    loop {
        if value <= 1 {
            break steps;
        }
        value /= 2;
        steps += 1;
    }
}
```

В примере `start` находится между `1` и `1000000`. Для `8` функция вернёт `3`, потому что последовательность значений равна `8`, `4`, `2`, `1`. Выражение `loop` стоит последним в теле функции, поэтому его результат становится результатом функции.

Команда `continue` пропускает оставшуюся часть текущего прохода. Обновлять счётчик нужно до такого перехода, иначе цикл может перестать продвигаться. Обычный `break` работает и в `for`, и в `while`, а возврат значения после `break` в рассмотренных циклах поддерживает только `loop`.
