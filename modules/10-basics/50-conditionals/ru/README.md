Стоимость доставки зависит от суммы заказа. В этом уроке вы выберете результат с помощью `if`, `else if` и `else`. Вы сможете описывать несколько тарифов одной функцией.

После `if` записывается выражение типа `bool`. Rust выполнит блок, если условие истинно. При ложном условии он перейдёт к следующей проверке или к `else`.

```rust
pub fn delivery(total: i32) -> i32 {
    if total >= 2000 {
        0
    } else if total >= 1000 {
        100
    } else {
        200
    }
}
```

Проверки идут сверху вниз. Для суммы `2500` сработает первая ветвь, и остальные уже не выполнятся. Для суммы `1500` результат равен `100`.

Само условное выражение возвращает значение выбранного блока. Поэтому все ветви должны давать совместимые типы. В примере каждая ветвь возвращает целое число без точки с запятой.

Иногда удобно завершить функцию раньше. Команда `return 0;` немедленно вернёт `0` вызывающему коду. Например, отдельная проверка некорректных данных в начале функции позволяет не вкладывать весь дальнейший расчёт в `else`.

Условие должно иметь тип `bool`. Числа и строки автоматически в него не преобразуются. Доступны сравнения `==`, `!=`, `<`, `<=`, `>` и `>=`. Для нескольких проверок используйте `&&` (и), `||` (или) и `!` (отрицание). Например, `total >= 1000 && total < 3000` проверяет попадание в средний тариф. Операторы `&&` и `||` вычисляют правую часть только тогда, когда её результат нужен.
