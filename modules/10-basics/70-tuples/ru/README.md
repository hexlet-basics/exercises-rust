Кортеж позволяет вернуть несколько связанных значений с разными типами. В этом уроке вы прочитаете тип кортежа, создадите его и разберёте на переменные. Число и типы элементов известны компилятору.

В типе `(i32, bool)` первым идёт целое число, вторым логическое значение. Элементы записываются в круглых скобках через запятую.

```rust
pub fn point() -> (i32, i32) {
    (3, 7)
}

pub fn show_point() {
    let position = point();
    let (x, y) = position;
    println!("x = {}, y = {}", x, y);
    println!("{:?}", position);
}
```

Объявление `let (x, y) = position;` распределяет элементы по именам. Такой разбор называется деструктуризацией. Можно обратиться и по позиции, например `position.0` или `position.1`. У этого кортежа оба элемента являются числами, поэтому после разбора исходный кортеж остаётся доступным.

Формат `{:?}` предназначен для отладочного представления. Последний вызов напечатает `(3, 7)`. Обычный формат `{}` поддерживают не все типы; для кортежа выберите отладочный.

Пустой кортеж `()` уже встречался как результат функции без полезного возвращаемого значения. Кортеж из одного элемента требует запятой, например `(10,)`. Скобки `(10)` просто группируют выражение и оставляют обычное число.

Кортеж подходит для короткой пары, смысл которой понятен из вызова. Для записи со многими именованными полями позже введём структуры.
