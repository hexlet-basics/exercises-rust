Массив Rust хранит элементы одного типа, а его длина входит в тип. В этом уроке вы прочитаете тип массива и получите элементы по индексу. Это поможет отличить фиксированный набор данных от растущего списка.

Запись `[i32; 3]` означает массив из трёх целых чисел. Значения записываются в квадратных скобках через запятую.

```rust
pub fn first_price() -> i32 {
    let prices: [i32; 3] = [100, 200, 300];
    prices[0]
}
```

Индексы начинаются с нуля и имеют тип `usize`. Метод `.len()` возвращает длину массива. В примере допустимы индексы `0`, `1` и `2`. Обращение за пределами вызывает панику, а некоторые очевидные выходы за границы компилятор обнаруживает заранее.

Массивы `[i32; 3]` и `[i32; 4]` имеют разные типы. В функцию с параметром `[i32; 3]` нельзя передать четыре элемента. Для повторяющегося значения есть запись `[0; 3]`, которая создаёт три нуля.

Массив чисел можно обойти через `for price in prices`. В этом случае цикл получает значения элементов. Передача массива из `i32` по значению оставляет исходный массив доступным. Причину такого поведения подробнее разберём вместе с владением. Для общего интерфейса к последовательностям любой длины дальше введём срезы.
