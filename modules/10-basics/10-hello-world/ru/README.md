Rust проверяет программу до запуска и компилирует её в исполняемый файл. В этом уроке вы познакомитесь с точкой входа и выводом на экран. Затем запустите первую функцию в редакторе Code Basics.

У самостоятельной программы точка входа называется `main`. Определение начинается с `fn`, а тело заключается в фигурные скобки.

```rust
fn main() {
    println!("Hello, World!");
}
```

Макрос `println!` печатает текст и перевод строки. Восклицательный знак отличает вызов макроса от вызова обычной функции. Подробное устройство макросов нам пока не понадобится. Команды завершаются точкой с запятой; её роль в возвращаемых значениях разберём отдельно.

Для подстановки данных используйте `{}` и аргументы после строки. Например, `println!("Total: {}", 150 * 4);` напечатает `Total: 600`. Числа и выражения записываются без кавычек. Комментарий начинается с `//` и продолжается до конца строки.

В Code Basics точку входа предоставляет среда. Вы дописываете готовую функцию, которую вызывает проверка.

```rust
pub fn greet() {
    println!("Hi, Rust!");
}
```

Слово `pub` делает функцию доступной проверке из другого модуля. Добавлять свою `main()` в упражнение не нужно. Пишите решение между `// BEGIN` и `// END`, сохраняя эти маркеры. Если компиляция не удалась, сначала исправьте указанную компилятором ошибку, затем запустите проверку снова.
