Знакомый алгоритм на Rust может не пройти компиляцию из-за ошибки типа или недопустимого доступа к данным. В этом уроке вы разберёте путь от исходного файла до запуска и прочитаете сообщение компилятора. Это поможет переносить опыт другого языка, учитывая ограничения Rust.

Курс предполагает, что вы уже знаете переменные, функции, условия и циклы. Мы быстро рассмотрим их запись, затем подробнее займёмся владением и ссылками. Rust проверяет типы и правила работы с памятью до запуска программы. Проверка заимствований запрещает некоторые операции даже тогда, когда они привычны в другом языке. Например, передача строки в функцию может передать ей владение данными. К этому вернёмся в модуле о владении.

## Компиляция и Cargo

Если захотите запускать примеры локально, установите Rust через [rustup](https://rustup.rs/). Вместе с компилятором устанавливается Cargo, который создаёт проекты, собирает их и управляет зависимостями. Локальная установка для упражнений Code Basics не требуется.

```bash
cargo new greeting
cd greeting
cargo run
```

Команда создаст каталог проекта. Файл `Cargo.toml` содержит его настройки, а `src/main.rs` содержит точку входа `fn main()`. Команда `cargo run` сначала компилирует программу, затем запускает получившийся исполняемый файл. В курсе используется Rust 2024 Edition, которую задаёт поле `edition = "2024"` в настройках проекта.

Для проверки типов без полноценной сборки исполняемого файла есть `cargo check`. Форматирование выполняется командой `cargo fmt`. В браузере запуск и проверку организует платформа, поэтому создавать Cargo-проект внутри упражнения не нужно.

## Чтение ошибки

Уберите восклицательный знак из знакомого вызова. Этот фрагмент намеренно неверен.

<!-- lint-code-blocks: skip — вызов макроса записан как вызов функции -->
```text
pub fn greet() {
    println("Hello, World!");
}
```

Компилятор сообщит, что `println` является макросом. В сокращённой диагностике видно место и подсказку.

```text
error[E0423]: expected function, found macro `println`
 --> src/lib.rs:2:5
  |
2 |     println("Hello, World!");
  |     ^^^^^^^ not a function
  |
help: use `!` to invoke the macro
```

Сначала прочитайте описание ошибки. Затем найдите строку в файле, которую отмечает компилятор. Подсказка `help` предлагает добавить `!`, и это исправляет конкретный вызов. После правки запустите проверку снова. Одно неверное место иногда вызывает несколько связанных сообщений, поэтому полезно начать с первой ошибки.
