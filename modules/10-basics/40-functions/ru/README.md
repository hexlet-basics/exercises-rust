Функции в Rust требуют типов параметров и явно задают тип результата. В этом уроке вы прочитаете сигнатуру функции и вернёте вычисленное значение. Особое внимание уделим точке с запятой в конце выражения.

После `fn` идут имя и параметры в круглых скобках. Каждый параметр получает тип. Стрелка `->` задаёт тип результата.

```rust
pub fn total(price: i32, count: i32) -> i32 {
    price * count
}

pub fn show_order() {
    let amount = total(200, 3);
    println!("{}", amount + 50);
}
```

Вызов `total(200, 3)` вернёт `600`. Аргументы связываются с параметрами по порядку. Второй функции останется прибавить доставку и напечатать `650`.

Последнее выражение тела без `;` становится результатом функции. Если написать `price * count;`, вычисленный результат будет отброшен. Тогда тело вернёт пустое значение `()`, которое не соответствует объявленному `i32`. Это частая причина ошибки компиляции при переносе привычек из другого языка.

Функция без `->` возвращает `()`, как `show_order` в примере. Для раннего завершения используется `return value;`. Оно немедленно передаёт значение вызывающему коду. Передача аргументов проверяется по типам до запуска программы, а имена параметров видны только внутри тела функции.

## Блок как выражение

Правило последнего выражения работает и у вложенных блоков. Их результат можно передать как аргумент. Здесь локальная переменная затеняет внешний параметр только внутри блока.

```rust
pub fn show_adjusted(value: i32) {
    println!("Adjusted: {}", {
        let value = value + 1;
        value * 2
    });
    println!("Original: {}", value);
}
```

В этом примере входное число по модулю не больше `1000000`. Для `value = 5` первый вывод даст `Adjusted: 12`. Внутреннее `value` содержит `6`, а последнее выражение блока возвращает удвоенное значение. После блока внешний параметр по-прежнему равен `5`, поэтому вторая строка будет `Original: 5`.

Точка с запятой после последнего выражения отбросила бы результат, и вместо числа блок вернул бы `()`. Значение блока можно также сохранить через `let result = { ... };`. Переменные, объявленные внутри фигурных скобок, доступны только в их области видимости.
