Rust проверяет типы во время компиляции и требует совместимых операндов в выражениях. В этом уроке вы зададите тип явно и разберёте числовые операции. Это поможет читать сигнатуры функций и ошибки о несовпадении типов.

Аннотация после имени задаёт тип переменной. Без неё Rust выводит тип по использованию значения. При отсутствии других ограничений целочисленный литерал получает `i32`, дробный получает `f64`.

```rust
pub fn show_average() {
    let total: f64 = 7.0;
    let count: f64 = 2.0;
    println!("{}", total / count);
}
```

Результат равен `3.5`. Для целых операндов `7 / 2` результат равен `3`, результат округляется к нулю, дробная часть отбрасывается. Например, `-7 / 2` даёт `-3`. Оператор `%` даёт остаток, поэтому `7 % 2` равно `1`. Скобки управляют приоритетом как в обычной арифметике.

Rust не приводит `i32` к `f64` автоматически при смешивании типов. Для явного числового преобразования есть `as`, например `let value = 7_i32 as f64;`. Суффикс `_i32` здесь задаёт тип литерала. Некоторые преобразования теряют данные, поэтому проверяйте диапазон и точность.

Семейство `i8`, `i16`, `i32`, `i64`, `i128` хранит целые со знаком, а `u8`, `u16`, `u32`, `u64`, `u128` хранит целые без знака. Число в имени задаёт количество битов. Беззнаковые типы не содержат отрицательных значений. Тип `i32` хранит целые со знаком в диапазоне от −2147483648 до 2147483647. Тип `usize` хранит беззнаковые размеры и индексы; его разрядность зависит от целевой платформы. Выход за диапазон при арифметике вызывает панику в обычной отладочной сборке; в стандартной сборке release целые переполняются с оборачиванием. В упражнениях используйте указанные ограничения входа.

Тип `bool` имеет значения `true` и `false`. Тип `char` представляет одно скалярное значение Unicode и записывается в одинарных кавычках, например `'Я'`. Текст `"Я"` в двойных кавычках является строкой. Дробные значения `f64` представляются приближённо, поэтому стоимость в дальнейших примерах храним целым числом денежных единиц.
