Модули Rust задают имена для частей программы и управляют доступом к ним. В этом уроке вы разберёте вложенный модуль и публичную функцию, затем вызовете её по пути. Затем сократите запись через `use`.

Модуль объявляется ключевым словом `mod`. Для первого знакомства весь код можно оставить в одном файле.

```rust
mod geometry {
    pub fn square_area(side: i32) -> i32 {
        side * side
    }
}

pub fn area() -> i32 {
    geometry::square_area(5)
}
```

Запись `geometry::square_area` является путём к функции. Функции внутри модуля по умолчанию скрыты от родительского модуля. Слово `pub` у `square_area` разрешает такой вызов. Сам `geometry` здесь доступен в родительском модуле, где он объявлен.

Подключить короткое имя можно записью `use geometry::square_area;`. Тогда в том же модуле можно писать `square_area(5)`. Конструкция `use` вводит имя в текущую область видимости. Она не устанавливает пакет и не делает скрытый элемент публичным.

Файлы проекта можно делить на модули. Объявление `mod geometry;` без тела обычно подключает модуль из файла `geometry.rs` или `geometry/mod.rs`. В упражнении эта раскладка не понадобится.

## Пакет и crate

Пакет Cargo описывается файлом `Cargo.toml`. Он может содержать библиотеку и исполняемые программы. Единицу компиляции Rust называют `crate`. У исполняемой программы есть точка входа `main`, а библиотека предоставляет код другим частям проекта. В пути `crate::geometry` слово `crate` обозначает начало текущей единицы компиляции.

Стандартная библиотека доступна как `std`. Например, путь `std::collections::HashMap` ведёт к типу хеш-таблицы, который мы разберём позднее. Команда `cargo add` добавляет внешнюю зависимость в настройки пакета. Для задач курса внешние пакеты устанавливать не нужно.

Знакомое `pub` в объявлениях упражнений позволяло тестовому модулю вызывать ваши функции. Теперь можно объяснить и назначение этой части каркаса.
