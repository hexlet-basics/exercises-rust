Возвращаемая ссылка должна оставаться действительной после выхода из функции. В этом уроке вы свяжете её с двумя входными ссылками с помощью аннотации времени жизни. Аннотация описывает допустимое использование данных и не продлевает их существование.

У каждой ссылки есть время, в течение которого доступны её данные. Rust часто выводит связь автоматически. У функции `fn prefix(text: &str) -> &str` один ссылочный аргумент, поэтому возвращаемая ссылка относится к нему. Но при двух ссылках без дополнительных сведений источник результата неоднозначен.

Следующая сигнатура намеренно неполная.

<!-- lint-code-blocks: skip — не указана связь возвращаемой ссылки с двумя входными -->
```text
fn first_non_empty(left: &str, right: &str) -> &str {
    if left.is_empty() { right } else { left }
}
```

Компилятор сообщит об отсутствующей аннотации времени жизни. Запись `'a` позволяет явно связать входные и возвращаемую ссылки.

```rust
pub fn first_non_empty<'a>(left: &'a str, right: &'a str) -> &'a str {
    if left.is_empty() {
        right
    } else {
        left
    }
}
```

Имя `'a` объявляется в угловых скобках после имени функции. Его повторение в трёх местах задаёт общее ограничение. Возвращаемой ссылкой можно пользоваться лишь в пределах, допускаемых обоими переданными заимствованиями. Сами строки могут существовать разное время.

На схеме показан участок, где доступны оба входа и результат такого вызова.

```text
left:   [-------------------------]
right:         [-----------]
result:        [-----------]
```

Если одна из строк типа `String` создана во внутреннем блоке, вынести результат и использовать его после завершения этого блока не получится. Проверка действует даже тогда, когда во время конкретного запуска функция выбрала бы более долгоживущую строку. Компилятор опирается на сигнатуру.

Аннотация не выделяет память и не превращает локальную строку в долгоживущую. Вернуть ссылку на созданную внутри функции `String` по-прежнему нельзя. Для нового текста возвращайте `String`, передавая владение.

Время жизни не задаёт длину текста. Метод `.len()` измеряет байты, а `'a` ограничивает действительность ссылки. Это разные свойства.
