Объявите `shorter<'a>(left: &'a str, right: &'a str) -> &'a str`. Верните ссылку на более короткую по числу байтов строку. При равной длине выбирайте `left`. Возвращайте один из входных срезов без создания новой строки.

Для `"cat"` и `"elephant"` результат равен `"cat"`. Пустая строка является допустимым входом.
