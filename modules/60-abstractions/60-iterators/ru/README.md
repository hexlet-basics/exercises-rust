Итератор хранит состояние последовательного получения элементов. В этом уроке вы вызовете `next`, сохраните итератор между вызовами и получите итог через потребитель. Это уточнит механизм, который раньше скрывался за `for`.

Метод `next` возвращает `Some` с очередным элементом либо `None`. Вызов меняет состояние итератора, поэтому переменная обычно требует `mut`.

```rust
pub fn show_range() {
    let mut numbers = 3..6;
    println!("{:?}", numbers.next());
    println!("{:?}", numbers.next());
    println!("{:?}", numbers.next());
    println!("{:?}", numbers.next());
}
```

Диапазон сам является итератором. Пример последовательно выведет `Some(3)`, `Some(4)`, `Some(5)` и `None`. Стандартный тип этого диапазона называется `std::ops::Range<i32>`.

Для коллекции выбор метода определяет, какие элементы получает итератор.

| Вызов для вектора | Элемент |
| --- | --- |
| `values.iter()` | Общая ссылка `&T` |
| `values.iter_mut()` | Изменяемая ссылка `&mut T` |
| `values.into_iter()` | Значение `T` с передачей владения |

Обход `for value in &values` соответствует общему доступу к элементам. Явный `iter` полезен, когда итератор нужно сохранить или передать как значение. `into_iter` у вектора потребляет исходную коллекцию.

## Потребители

Метод `count` считает оставшиеся элементы, `sum` складывает их, `max` ищет максимум. Эти методы потребляют итератор. Для суммы может понадобиться явно указать тип результата.

```rust
pub fn summarize() {
    let values = vec![3, 7, 2];
    let total: i32 = values.iter().sum();
    let count = values.iter().count();
    let largest = values.iter().max();
    println!("{} items, sum {}, max {:?}", count, total, largest);
}
```

Каждый вызов `values.iter()` создаёт новый итератор. Вектор остаётся доступным. Максимум представлен как `Option<&i32>`, потому что коллекция может быть пустой и выбран общий обход.

Для пары из индекса и элемента есть `enumerate`. Цикл `for (index, value) in values.iter().enumerate()` получает индекс типа `usize` и ссылку на элемент. Кортеж можно разобрать прямо в заголовке цикла.

Готовые итераторы реализуют трейт `Iterator`. Создавать свою реализацию в этом курсе не нужно. Дальше мы соединим получение элементов с преобразованием и отбором, которые выполняются по мере потребления.
