Замыкание Rust можно сохранить в переменную и передать другой функции. В этом уроке вы зададите преобразование через `|...|` и используете значение из окружающего кода. Для практики достаточно замыкания, которое читает окружение.

Параметры записывают между вертикальными чертами. После них идёт выражение либо блок. Типы часто выводятся по использованию.

```rust
pub fn above_threshold(value: i32, threshold: i32) -> bool {
    let is_large = |number: i32| number > threshold;
    is_large(value)
}
```

Вызов `above_threshold(12, 10)` вернёт `true`. У замыкания один параметр `number`, а `threshold` доступен из окружения. Такой доступ называют захватом. Здесь значение только читается. Если захвату нужна ссылка на данные, правила общего заимствования продолжают действовать.

## Функция как аргумент

Поведение вызываемого аргумента можно описать через `impl Fn`.

```rust
pub fn apply(value: i32, operation: impl Fn(i32) -> i32) -> i32 {
    operation(value)
}

pub fn triple(value: i32) -> i32 {
    apply(value, |number| number * 3)
}
```

Для примера `value` по модулю не больше `1000000`. Запись `Fn(i32) -> i32` требует вызываемое значение, которое принимает число и возвращает число. `impl Trait` в аргументе уже знаком по ограничениям трейтов. После подстановки замыкания функция `apply` сама решает, когда его вызвать.

Замыкание с одной сигнатурой сохраняет выведенные типы. Нельзя сначала вызвать одно и то же сохранённое замыкание с числом, затем ожидать от него независимой подстановки строки как от обобщённой функции.

Ещё один частый случай связан с сортировкой по ключу.

```rust
pub fn sorted_points() -> Vec<(i32, i32)> {
    let mut points = vec![(3, 1), (2, 4), (7, 0)];
    points.sort_by_key(|point| point.1);
    points
}
```

Замыкание получает ссылку на элемент и возвращает его второй компонент как ключ. В итоге порядок задаётся вторыми координатами. Мы выбираем ключ числового типа, который поддерживает `Ord`.

Замыкания могут также менять или забирать захваченные данные, но тогда нужны другие виды вызываемого поведения. Их самостоятельное применение выходит за границы этого урока. В упражнении замыкание читает числовой параметр.
