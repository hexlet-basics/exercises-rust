Адаптеры итераторов позволяют описать отбор и преобразование последовательности. В этом уроке вы соедините `filter` и `map`, затем соберёте результат через `collect`. Разберёте, почему создание такой цепочки само по себе ещё не выполняет обработку.

Метод `map` получает замыкание и превращает каждый выдаваемый элемент в новое значение. Тип результата может отличаться от типа входного элемента.

```rust
pub fn long_lengths(names: &[String]) -> Vec<usize> {
    names
        .iter()
        .map(|name| name.len())
        .filter(|length| *length >= 4)
        .collect()
}
```

В примере строки `"Ada"`, `"Grace"` и `"Edsger"` превращаются в длины `3`, `5` и `6`, затем фильтр оставляет `[5, 6]`. Метод `filter` оставляет элементы, для которых замыкание вернуло `true`, а `collect` потребляет итератор и собирает новую коллекцию. Тип `Vec<usize>` известен из возвращаемого типа функции. В локальном объявлении можно написать `let result: Vec<usize> = ...collect();`.

## Ссылки в замыканиях

Для среза чисел метод `iter` выдаёт `&i32`. Замыкание `filter` проверяет элемент по ссылке, поэтому получает `&&i32`. Два знака `*` в `**value` добираются до числа. Сам `filter` сохраняет исходный тип выдаваемого элемента, поэтому следующий `map` снова получает `&i32` и требует один `*`.

При `into_iter` у вектора итератор выдавал бы сами числа. Тогда `filter` получил бы `&i32`, а `map` получил бы `i32`. Число ссылок определяется всей цепочкой.

## Ленивое выполнение

Адаптер создаёт новый итератор, который выполняет работу при запросе элементов потребителем.

```rust
pub fn show_processing() {
    let values = [1, 2];
    let transformed = values.iter().map(|value| {
        println!("Processing {}", value);
        *value + 1
    });
    println!("Iterator created");
    let result: Vec<i32> = transformed.collect();
    println!("{:?}", result);
}
```

Сначала появится `Iterator created`. Затем `collect` начнёт запрашивать элементы и выполнит замыкание. После строк о двух обработанных значениях программа выведет `[2, 3]`. Если не потреблять итератор, обработка в `map` не запустится. Неиспользованный результат адаптера также может вызвать предупреждение компилятора.

Общий обход сохраняет исходную коллекцию. Новый вектор в примере содержит вычисленные числа и владеет своим буфером. Выбирайте способ обхода по тому, должны ли исходные данные остаться доступны.
