Обобщённая функция работает с разными типами, сохраняя проверку на этапе компиляции. В этом уроке вы объявите собственный параметр типа `T` и используете его в сигнатуре. Владение переданными значениями будет действовать по тем же правилам, что и у конкретного типа.

Запись `<T>` после имени вводит параметр типа. Вместо него можно подставить `i32`, `String` или свой тип.

```rust
pub fn identity<T>(value: T) -> T {
    value
}

pub fn show_identity() {
    let number = identity(42);
    let text = identity(String::from("Rust"));
    println!("{}: {}", text, number);
}
```

В первом вызове Rust выводит `T = i32`, во втором `T = String`. Явная форма выглядит как `identity::<i32>(42)`. Она нужна, если из аргументов и ожидаемого результата тип определить нельзя.

Параметр `T` не превращает значение в динамический контейнер неизвестного типа. Rust проверяет тело функции с учётом заявленных возможностей `T`. При вызове компилятор проверяет, что подставленный тип им соответствует, и формирует для него исполняемый код.

Число в примере копируется при передаче, а `String` перемещает владение в функцию и обратно через результат. Обобщённость не добавляет автоматическое копирование. Если функция только читает данные, параметр можно объявить как `&T`.

Типы `Vec<T>` и `Option<T>` уже знакомы. Например, результат `Option<T>` означает, что функция вернёт значение того же выбранного типа либо `None`. Метод `Vec::pop` умеет перемещать последний элемент наружу без его копирования.

Параметр функции можно сделать изменяемым в сигнатуре, например `fn process<T>(mut values: Vec<T>)`. Это разрешает менять значение внутри вызова. Другой знакомый способ состоит в объявлении `let mut values = values;` в теле.

Для произвольного `T` нельзя просто написать сложение, сравнение или вызвать `clone`. Такие действия доступны только при нужных ограничениях. В следующих уроках опишем их с помощью трейтов.
