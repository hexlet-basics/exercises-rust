Готовый трейт `Named` требует метод `label(&self) -> String` и предоставляет метод `label_length` по умолчанию. Реализуйте `Named` для структур `Book` и `User`.

Для книги верните строку `"Book: "` с её `title`, для пользователя строку `"User: "` с его `name`. Например, книга с названием `"Rust"` даёт `"Book: Rust"`. Исходные строки менять и перемещать из общей ссылки нельзя. Оба значения могут быть пустыми. Метод `label_length` переопределять не нужно.
