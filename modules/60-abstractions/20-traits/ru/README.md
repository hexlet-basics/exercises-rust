Трейт задаёт общее поведение для разных типов. В этом уроке вы разберёте объявление трейта и реализуете его для двух структур. Компилятор потребует выполнить все обязательные части такого соглашения.

В объявлении `trait` указываются сигнатуры методов. Тело обязательного метода заменяется точкой с запятой.

```rust
pub trait HasArea {
    fn area(&self) -> i32;

    fn is_empty(&self) -> bool {
        self.area() == 0
    }
}

pub struct Rectangle {
    pub width: i32,
    pub height: i32,
}

impl HasArea for Rectangle {
    fn area(&self) -> i32 {
        self.width * self.height
    }
}
```

Для примера размеры неотрицательные и не больше `1000`. Блок `impl HasArea for Rectangle` связывает поведение с типом. Метод `area` обязателен, а `is_empty` уже имеет реализацию по умолчанию. Она вызывает метод того экземпляра, для которого выполняется проверка.

После объявления `let rectangle = Rectangle { width: 3, height: 4 };` вызов `rectangle.area()` вернёт `12`, а `rectangle.is_empty()` вернёт `false`. Другой тип, например квадрат, может реализовать тот же трейт своим способом.

Внутри реализации метода трейта не добавляют отдельное `pub`. Доступ задаётся объявлением самого трейта. Если тип и трейт находятся в другом модуле, для обычного вызова через точку имя трейта нужно привести в область видимости через `use`.

Метод по умолчанию можно переопределить, но это не обязательно. Трейт описывает доступное поведение и не добавляет структуре новые поля. Условия вида «функция принимает любой тип с этим поведением» рассмотрим следующим уроком.
