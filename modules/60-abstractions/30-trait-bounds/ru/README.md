Ограничение трейта сообщает, какие операции доступны обобщённой функции. В этом уроке вы добавите `T: Trait` и прочитаете равнозначную запись с `impl Trait` в аргументе. Это позволит использовать поведение типа без перечисления всех допустимых типов вручную.

У произвольного `T` компилятор не может предполагать отладочный вывод. Ограничение `Debug` разрешает формат `{:?}`.

```rust
use std::fmt::Debug;

pub fn show<T: Debug>(value: &T) {
    println!("{:?}", value);
}

pub fn show_short(value: &impl Debug) {
    println!("{:?}", value);
}
```

Второй вариант удобен, когда параметр типа не нужно связывать с другими местами сигнатуры. В обоих случаях аргумент должен поддерживать `Debug`. Если один и тот же тип нужен у нескольких параметров или в результате, явное имя `T` показывает эту связь.

Несколько требований объединяются знаком `+`. Длинное ограничение можно вынести после сигнатуры с помощью `where`.

```rust
pub fn duplicate<T>(value: &T) -> T
where
    T: Clone + Debug,
{
    println!("{:?}", value);
    value.clone()
}
```

Ссылка позволяет прочитать значение, а `Clone` разрешает получить отдельное значение `T`. Без ограничения такой вызов `clone` не был бы гарантирован для произвольного типа.

## Знакомое стандартное поведение

Ранее часть трейтов встречалась через готовые типы и `derive`. Теперь можно связать имена с операциями.

| Трейт | Доступное поведение |
| --- | --- |
| `Copy` | Неявное копирование при присваивании и передаче |
| `Clone` | Явный вызов `clone` |
| `Debug` | Отладочное представление `{:?}` |
| `PartialEq` | Сравнение значений через `==` и `!=` |
| `PartialOrd` | Сравнение через `<`, `>`, `<=`, `>=`, допускающее несравнимые значения |
| `Ord` | Полный порядок, подходящий обычной сортировке |

`Ord` требует `PartialOrd`, поэтому для параметра `T: Ord` эти операторы сравнения тоже доступны. При сравнении ссылок `&T` они сравнивают сами значения. У `i32` есть полный порядок. У `f64` значения `NaN` могут быть несравнимы, поэтому `Ord` для них нет. Это объясняет ограничение обычного `sort` из урока о коллекциях.

Атрибут `#[derive(Debug, PartialEq)]` просит компилятор автоматически реализовать указанное поведение структуры или перечисления на основе полей. Все поля должны поддерживать нужные операции. `Copy` также требует `Clone` и подходит только для типов, чьи поля допускают такое копирование. Структуре со `String` нельзя просто добавить `Copy`.

Ограничение `Ord` не требует копировать значение при сравнении. Можно вернуть ссылку на найденный элемент, сохранив исходную коллекцию. Метод среза `first()` возвращает ссылку на первый элемент в `Some` либо `None` для пустого среза. Если в аргументах одна ссылка на срез, возвращаемая ссылка связывается с ней без явной аннотации времени жизни.
