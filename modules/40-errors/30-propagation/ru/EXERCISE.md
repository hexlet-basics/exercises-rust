Готовая функция `check_even(value: i32) -> Result<i32, String>` возвращает `Err(String::from("negative"))` для отрицательного числа и `Err(String::from("odd"))` для неотрицательного нечётного. Для допустимого числа она возвращает `Ok(value)`.

Допишите `sum_even(left: i32, right: i32) -> Result<i32, String>`. Сначала проверьте `left` через `check_even`, затем `right`. Передавайте первую ошибку через `?`. При успехе верните сумму проверенных чисел в `Ok`.

Оба аргумента находятся между `-1000000` и `1000000`. Для `2` и `4` результат равен `Ok(6)`. Для `-2` и `3` вернётся ошибка `"negative"`, поскольку проверка левого аргумента выполняется первой.
