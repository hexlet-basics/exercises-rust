Перечисление Rust задаёт несколько допустимых вариантов одного типа. В этом уроке вы объявите `enum` и создадите вариант с дополнительными данными. Такой тип помогает исключить состояния, которые не имеют смысла для задачи.

Вариант может не содержать данных или хранить значения заданных типов.

```rust
#[derive(Debug, PartialEq)]
pub enum Message {
    Quit,
    Text(String),
    Position(i32, i32),
}

pub fn greeting() -> Message {
    Message::Text(String::from("Hello"))
}
```

Значение `Message::Quit` описывает завершение без дополнительных данных. Значение `Message::Text(String::from("Hello"))` хранит строку. Вариант `Message::Position(3, 7)` хранит две координаты. Путь через `::` указывает, какому перечислению принадлежит вариант.

Перечисление хранит один вариант за раз. Нельзя одновременно получить `Quit` и `Text` или создать `Text` без строки. Если данные принадлежат варианту, Rust проверяет их типы при создании.

Вариант с данными можно создать из аргументов функции.

```rust
pub fn position(x: i32, y: i32) -> Message {
    Message::Position(x, y)
}
```

Вызов `position(3, 7)` создаёт вариант с двумя переданными координатами. Варианты можно возвращать и из разных ветвей `if`, поскольку все они относятся к одному типу. Передача готовой строки в `Message::Text` перемещает владение внутрь значения перечисления.

Готовый `#[derive(Debug, PartialEq)]` позволяет печатать значение в отладочном виде и сравнивать его с ожидаемым в тестах. Чтобы извлечь данные неизвестного заранее варианта, понадобится `match`. Его разберём следующим уроком.
