Поля с именами помогают объединить название и число страниц книги. В этом уроке вы объявите `struct`, создадите экземпляр и прочитаете его поля. Затем передадите структуру функции по ссылке.

В определении указываются имена и типы полей. В примерах курса `pub` у полей позволяет проверке создавать значения из другого модуля.

```rust
pub struct Book {
    pub title: String,
    pub pages: i32,
}

pub fn is_short(book: &Book) -> bool {
    book.pages < 100
}
```

Экземпляр создаётся записью `Book { title: String::from("Rust"), pages: 80 }`. Имена полей указываются явно, а порядок записи можно менять. Доступ к полю идёт через точку. Вызов `is_short(&book)` читает число страниц и оставляет экземпляр у владельца.

Чтобы менять поля, объявите владельца с `mut`, например `let mut book = Book { title: String::from("Rust"), pages: 80 };`. Тогда запись `book.pages = 120;` обновит число страниц. Отдельной настройки изменяемости для каждого поля нет.

Собственные структуры по умолчанию перемещаются при присваивании, даже если все поля являются числами. Поддержку `Copy` можно добавить явно при выполнении условий, но в этом курсе мы используем перемещение и ссылки. Если переместить поле `title` типа `String` в другую переменную, экземпляр `book` целиком использовать уже нельзя. Поля, которые ещё не переместили, например `book.pages`, остаются доступны.

Для своих типов отладочный вывод можно включить готовым атрибутом `#[derive(Debug, PartialEq)]` перед `pub struct`. Часть `Debug` разрешает отладочный вывод через `{:?}`, а `PartialEq` разрешает сравнивать значения через `==`, если поля поддерживают нужные операции. Это автоматическая реализация стандартного поведения. Связь этого атрибута с трейтами разберём в уроке об ограничениях трейтов.
