Поведение, связанное с типом, можно описать в блоке `impl`. В этом уроке вы добавите структуре метод и выберете вид доступа к экземпляру через `self`. Это позволит вызывать расчёт через точку у товара.

Метод объявляется как функция внутри `impl ИмяТипа`. Первый параметр `&self` означает общую ссылку на экземпляр.

```rust
pub struct Product {
    pub price: i32,
    pub count: i32,
}

impl Product {
    pub fn total(&self) -> i32 {
        self.price * self.count
    }
}
```

Для `let product = Product { price: 200, count: 3 };` вызов `product.total()` вернёт `600`. Rust сам создаёт нужную ссылку для вызова метода, поэтому писать `(&product).total()` не требуется.

Параметр `&mut self` даёт методу изменяемый доступ. Для вызова подойдёт экземпляр в переменной с `mut` или уже полученная ссылка `&mut Product`. Параметр `self` передаёт владение экземпляром методу. Выбор соответствует обычным параметрам `&Product`, `&mut Product` и `Product`.

Функции внутри `impl` называют связанными функциями. Если у такой функции есть параметр `self`, она является методом. Функцию без `self` вызывают через `Product::имя()`. Такой синтаксис уже встречался в `String::from`. Метод с `&self` подходит для расчётов, после которых экземпляр должен оставаться доступным.

Связанная функция для создания экземпляра может выглядеть как `pub fn new(price: i32, count: i32) -> Self { Self { price, count } }` внутри `impl Product`. Имя `Self` обозначает текущий тип, а сокращение `price` в списке полей означает `price: price`. Вызов `Product::new(200, 3)` создаст тот же экземпляр. Имя `new` является соглашением и не имеет специальной семантики.
