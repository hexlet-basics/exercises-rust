Выражение `match` выбирает действие по образцу и извлекает данные перечисления. В этом уроке вы обработаете все варианты своего типа и добавите условие к ветви. Компилятор проверит, что возможные значения не забыты.

У каждой ветви есть образец слева от `=>` и результат справа. Если образец содержит имя, Rust связывает его с данными варианта.

```rust
pub enum Payment {
    Pending,
    Paid(i32),
}

pub fn is_large_payment(payment: Payment) -> bool {
    match payment {
        Payment::Paid(amount) if amount >= 1000 => true,
        Payment::Paid(_) => false,
        Payment::Pending => false,
    }
}
```

Образец `Payment::Paid(amount)` извлекает сумму в локальную переменную. Проверка после `if` называется охранным условием. Если сумма меньше `1000`, Rust продолжает выбирать следующую ветвь и попадает в `Paid(_)`. Подчёркивание принимает данные без создания имени.

Ветви проверяются по порядку. Без обработки `Pending` пример не скомпилируется. Охранное условие не заменяет полноту, поэтому для `Paid` остаётся ветвь на остальные суммы. Все ветви выражения должны возвращать совместимые типы, здесь это `bool`.

Сопоставлять можно и скалярные значения.

```rust
pub fn is_weekend(day: i32) -> bool {
    match day {
        6 | 7 => true,
        _ => false,
    }
}
```

Знак `|` объединяет образцы, а `_` принимает любое оставшееся число. Общую ветвь размещайте последней, иначе она закроет более конкретные случаи.

Параметр `Payment` передаётся по значению. Если в варианте находилась бы `String`, извлечение в такую ветвь передало бы ей владение. При сопоставлении с `&Payment` образец `Payment::Paid(amount)` связывает `amount` с общей ссылкой типа `&i32`. Для числового сравнения через такую привязку прочитайте `*amount`.
