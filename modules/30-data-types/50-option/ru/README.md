Поиск может завершиться без найденного значения. В этом уроке вы выразите такой исход через `Option<T>` и обработаете оба варианта. Число `0` при этом сможет оставаться обычным результатом.

Стандартное перечисление `Option<T>` содержит `Some(T)` для найденного значения и `None` для отсутствующего. Буква `T` является параметром типа. Запись `Option<i32>` подставляет на её место целое число. Варианты `Some` и `None` доступны без полного имени `Option::`.

Метод массива `get` возвращает `Option` со ссылкой на элемент. Так индекс можно проверить без паники.

```rust
pub fn at(values: &[i32; 3], index: usize) -> Option<i32> {
    match values.get(index) {
        Some(value) => Some(*value),
        None => None,
    }
}
```

Здесь `&[i32; 3]` является ссылкой на массив ровно из трёх чисел. Вызов `at(&[0, 5, 7], 0)` вернёт `Some(0)`. Индекс `3` даст `None`. Внутри ветви `Some` имя `value` имеет тип `&i32`, поэтому для копирования числа используется `*`.

Варианты можно обработать через знакомый `match`, а для действия только при наличии значения подходит `if let`.

```rust
pub fn show_at(values: &[i32; 3], index: usize) {
    if let Some(value) = at(values, index) {
        println!("{}", value);
    }
}
```

Когда результат равен `None`, тело просто пропускается. При двух содержательных исходах `match` позволяет явно описать оба.

Метод `unwrap()` извлекает содержимое `Some`, но паникует на `None`. Для запасного значения есть `unwrap_or`. Например, `at(&[0, 5, 7], 8).unwrap_or(-1)` вернёт `-1`. Такой запасной результат выбирает вызывающий код, он не является встроенным признаком отсутствия у `i32`.

У `Option<String>` содержимое уже является строкой с владением. При извлечении из `Some` по значению строка перемещается. Поведение `Option` согласуется с правилами того типа, который он хранит.
