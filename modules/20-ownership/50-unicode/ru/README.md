Число байтов в строке Rust может отличаться от числа символов. В этом уроке вы обойдёте текст через `.chars()` и сравните элементы типа `char`. Так можно обработать кириллицу и другие символы, которые занимают несколько байтов в UTF-8.

Строки `String` содержат корректный текст UTF-8. Метод `.len()` возвращает размер в байтах типа `usize`. У текста `"Я!"` это три байта, хотя при обходе получится два значения `char`.

```rust
pub fn show_characters() {
    let text = String::from("Я!");
    println!("Bytes: {}", text.len());
    for character in text.chars() {
        println!("{}", character);
    }
    println!("Text: {}", text);
}
```

Метод `chars` предоставляет последовательность скалярных значений Unicode. Цикл получает очередной `char` в переменную `character`. Для сравнения используйте одинарные кавычки, например `character == '!'`. Обход читает строку и оставляет её доступной после цикла.

Индексация `text[0]` у строк не поддерживается. Число могло бы означать позицию байта, скалярного значения или видимого знака. Эти позиции не обязаны совпадать. Для обхода значений `char` выбирайте `.chars()`.

Один видимый знак тоже может состоять из нескольких `char`. Например, букву и комбинируемый знак ударения можно хранить отдельно. Некоторые эмодзи состоят из нескольких скалярных значений. Поэтому результат обхода `chars` не следует без оговорки называть числом видимых знаков.

Регистр и Unicode-представление сравниваются буквально. Строчная буква сама по себе не станет равной заглавной. В следующем уроке разберём срезы текста и причину проверки их байтовых границ.
