Изменяемый текст в Rust обычно хранится в `String`. В этом уроке вы создадите строку из литерала и дополните её методом `push_str`. Это подготовит нас к разбору владельца строковых данных.

Запись `String::from("Book")` создаёт строку, которая владеет своими данными. Пара символов `::` обращается к функции, связанной с типом. Такая функция вызывается без готового экземпляра строки.

```rust
pub fn book_title() -> String {
    let mut title = String::from("Rust");
    title.push_str(" handbook");
    title
}
```

Метод вызывается через точку у уже существующего значения. Метод `push_str` дописывает текст в конец строки и меняет её, поэтому переменная `title` объявлена с `mut`. Результат функции равен `"Rust handbook"`.

Для добавления одного символа есть метод `push`, например `title.push('.')`. В знакомом цикле `for _ in 0..3` тело выполняется три раза. Подчёркивание означает, что значение очередного элемента диапазона не понадобится в теле.

Строковый литерал `"Rust"` и значение `String` имеют разные типы. Литерал представляет ссылку на неизменяемый текст, а `String` управляет собственным буфером, который может расти. Литерал имеет тип `&str`. Подробно его разберём после ссылок.

В `String` текст хранится в кодировке UTF-8. Метод `.len()` возвращает количество байтов типа `usize`. Для латинского `"Rust"` это `4`, а для `"Я"` это `2`. Поэтому длину строки в байтах нельзя во всех случаях использовать как количество букв.

Для создания новой строки из значений подходит `format!`. Например, `format!("Total: {}", 200 * 3)` возвращает `String` со значением `"Total: 600"` и ничего не печатает. Форматирование работает по тем же правилам, что в `println!`.
