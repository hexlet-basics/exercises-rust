Допишите `first_half(text: &str) -> &str`. Верните срез первой половины строки. Если длина нечётная, округлите число байтов вниз. Вход содержит только ASCII-символы, поэтому любая позиция между байтами является допустимой границей.

Для `"abcdef"` верните `"abc"`, для `"abcde"` верните `"ab"`. Пустая строка и строка из одного символа должны давать пустой срез. Возвращайте часть исходного текста.
