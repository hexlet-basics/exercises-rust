Для чтения текста в Rust обычно используют параметр `&str`. В этом уроке вы передадите одной функции литерал и `String`, затем вернёте заимствованную часть строки. Буфер исходного текста при этом не копируется.

Тип `str` описывает корректную последовательность байтов UTF-8. Ссылка `&str` содержит доступ к байтам и их длину. Строковый литерал уже имеет тип `&str`. Когда функция ожидает `&str`, Rust может преобразовать переданный `&String` в нужный вид ссылки.

```rust
pub fn is_source_file(name: &str) -> bool {
    name.ends_with(".rs")
}

pub fn show_checks() {
    let name = String::from("main.rs");
    println!("{}", is_source_file(&name));
    println!("{}", is_source_file("index.rs"));
}
```

Метод `ends_with` проверяет конец строки, `starts_with` проверяет начало, а `is_empty` проверяет отсутствие текста. Функция `is_source_file` читает разные источники текста через один интерфейс.

## Часть строки

Выражение `&name[0..2]` создаёт ссылку на часть строки. Левая граница включается, правая не включается. Начальную границу `0` можно опустить, записав `&name[..2]`. Позиции измеряются в байтах.

```rust
pub fn first_three(text: &str) -> &str {
    &text[..3]
}
```

Этот пример рассчитан на ASCII-строку длиной не меньше трёх байтов. Вызов `first_three("abcdef")` вернёт `"abc"`. Границы среза должны находиться внутри строки и совпадать с границами символов UTF-8. Если взять первый байт строки `"Я"`, выполнение завершится паникой, потому что символ занимает два байта. В упражнении ASCII-вход гарантирован, поэтому граница между байтами всегда совпадает с границей символа.

Результат `first_three` ссылается на входные данные. У функции один ссылочный параметр, и Rust связывает возвращаемую ссылку с ним без явной аннотации. Вызывающий код сможет использовать результат, пока исходная строка доступна. Возвращать ссылку на созданную внутри функции `String` нельзя, поскольку её буфер освобождается при выходе.

Выбирайте `String`, когда нужен новый владелец, `&mut String` для изменения буфера и `&str` для чтения текста. Срез сам не владеет байтами и не освобождает их.
