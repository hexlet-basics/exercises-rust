Готовая функция `add_exclamation(text: &mut String)` добавляет один знак `'!'`. Допишите `emphasize(text: String) -> String`. Сделайте полученную строку локально изменяемой, дважды последовательно передайте `&mut` на неё в готовую функцию, затем верните строку.

Для `"Rust"` результат равен `"Rust!!"`, для пустой строки `"!!"`. Каждый вызов должен завершить своё заимствование перед следующим.
