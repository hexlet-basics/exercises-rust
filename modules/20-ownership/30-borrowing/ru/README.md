Функция может прочитать данные, сохранив владение у вызывающего кода. В этом уроке вы передадите общую ссылку и прочитаете значение через неё. Для строки это позволяет обойтись без перемещения и копирования буфера.

Знак `&` перед значением создаёт общую ссылку. В типе `&i32` он означает ссылку на целое число.

```rust
pub fn plus_ten(value: &i32) -> i32 {
    *value + 10
}

pub fn show_value() {
    let number = 5;
    let result = plus_ten(&number);
    println!("{} -> {}", number, result);
}
```

Оператор `*value` читает число по ссылке. Функция вернёт `15`, исходная переменная сохранит `5`. Для `i32` передача по значению тоже оставила бы оригинал доступным, потому что числа копируются. Отличие становится существенным на `String`, у которой передача по значению перемещает владение.

```rust
pub fn show_title() {
    let title = String::from("Rust");
    let reference = &title;
    println!("Bytes: {}", reference.len());
    println!("{}", title);
}
```

Общая ссылка `reference` читает тот же буфер. После её использования переменная `title` по-прежнему владеет строкой. В вызове метода Rust автоматически разыменовывает ссылку, поэтому для `.len()` не нужно вручную писать `*`.

Одновременно может существовать несколько общих ссылок на данные. Изменять данные через них нельзя. Оператор `==` при сравнении ссылок на такие значения сравнивает сами значения. Например, `&5 == &5` даёт `true`, хотя записи ссылок созданы отдельно. Операторы `<` и `>` для ссылок на числа тоже сравнивают сами значения. Проверка идентичности адресов устроена иначе и для упражнения не нужна.

На схеме владелец и ссылка обращаются к одному буферу.

```text
title     -- владеет --> [буфер "Rust"]
                              ^
                              |
reference -- читает ----------+
```

Rust проверяет, что заимствованные данные доступны во время использования ссылки. Общая ссылка не освобождает буфер. Для изменения через ссылку понадобится `&mut T`, а для общего интерфейса чтения текста позже выберем `&str`.
